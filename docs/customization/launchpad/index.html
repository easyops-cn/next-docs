个性化桌面配置

EasyOps 5.0 提供了桌面（LaunchPad）配置的能力，如图所示：

包括：

  • 分类及微应用归属都可个性化配置
  • 可对桌面设置权限，限制只有部分人可访问

自定义分类​

桌面配置是保存在一个 CMDB 的模型里面的，模型 ID 为_MICROAPP_CONTAINER，配置方式：

  1. 进入【模型设置】，点击右上角【更多操作】-【已隐藏的模型】
  2. 搜索关键字_MICROAPP_CONTAINER，点击进入“应用桌面容器”的详情
  3. 点击右上角【实例列表】进入实例列表，如下图所示：
  4. 新建实例，如创建“我的应用”的分类，其中排序为分类的顺序
  5. 点击左侧栏小产品，添加应用到该容器。注意：如果某 app 已经归属到其他容器，这里候选列表不会显示，如果需要调整，请到对应的容器先移除该 app。
  6. 你也可以创建一个文件夹，其容器类型为 dir，请参考现有修改
